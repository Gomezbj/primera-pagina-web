# Mi primera página web

Este proyecto es un sitio web personal tipo portafolio, creado como práctica durante un curso de HTML y CSS. **Fue mi primera página web**, así que representa uno de mis primeros pasos aprendiendo desarrollo web.

> **Importante:** el sitio no es responsive; su diseño no está adaptado a todos los tamaños de pantalla y puede visualizarse mejor en una computadora.

## Secciones

- **Inicio:** presentación e información personal.
- **Conocimientos:** temas y herramientas que estoy aprendiendo.
- **Trabajos:** experiencia laboral.
- **Contacto:** formulario y datos de contacto.

## Tecnologías

- HTML
- CSS

## Cómo verlo

Clona o descarga este repositorio y abre `index.html` en tu navegador. No requiere instalación de dependencias ni un proceso de compilación.

## Estructura

- `index.html`: página de inicio.
- `Conocimientos.html`: sección de conocimientos.
- `trabajos.html`: sección de trabajos.
- `Contacto.html`: sección de contacto.
- `css/`: hojas de estilo.
- `img/`: imágenes y recursos gráficos.
